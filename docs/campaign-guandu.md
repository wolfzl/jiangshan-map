# 官渡之战阶段与史料说明

入口：东汉，公元 200 年，「官渡 · 京口」编年事件；URL 参数为 `campaign=guandu&cphase=1`。首阶段回到 199 年，战役年份范围为 199—200 年。

## 兵力与地理边界

- 不展示双方总兵力。《武帝纪》及裴注等对兵力的叙述存在争议，避免把演义中的数字当作确定事实。夜袭部队「步骑五千」依《武帝纪》记述。
- 官渡使用 `map_data.js` 的事件坐标 `[114.001, 34.751]`；白马使用 `lore_data.js` 的白马之战坐标 `[114.53, 35.61]`。
- 乌巢采用延津一带的示意位置，避免把地名索引中与官渡共用的「乌巢」别名坐标误当作粮屯精确位置。
- 古黄河河道及渡口位置与现代水系不完全重合。黎阳、白马、延津及北撤路线按古渡口关系示意，不能按现代黄河线解读。
- 官渡两军营垒、袭粮地点与夜袭绕行线均为示意；路线不声称精确到村落或营门。
- 文丑战死不注明凶手；不用演义「关羽斩文丑」。张郃降曹前后的记载存在叙事差异，采用乌巢失守、攻曹营不下后投降的顺序，不表现郭图谗言等争议细节。
- 火攻用现有交战标记及文字表达，不增加图标或修改渲染逻辑。经用户确认，在现有战术尺度隐藏规则中补充 `.polity-caption`，避免底图势力大字遮挡路线；退出推演或回到战略尺度后恢复。
